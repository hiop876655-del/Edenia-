مشروع ايدينيا - حِسبة (برنامج ويندوز أصلي C# .NET 8 WPF)
=========================================================

طريقة فتح وتشغيل المشروع:

الخيار الأول (بواسطة Visual Studio):
1. اضغط مرتين على ملف: IdeniaHisba.sln
2. سيفتح المشروع في Visual Studio.
3. اضغط F5 أو زر تشغيل (Start) لتشغيل البرنامج وتجربته.
4. لتوليد ملف EXE: اضغط Build > Publish > Folder.

الخيار الثاني (بواسطة سطر الأوامر أو ملف البناء التلقائي):
1. اضغط مرتين على ملف "بناء_وتشغيل_البرنامج.bat".
2. سيقوم تلقائياً بتجميع الكود وتحميل مكتبات SQLite وإنشاء ملف IdeniaHisba.exe مستقل تماماً داخل مجلد dist-exe.

المميزات:
- قاعدة بيانات SQLite محلية لا تحتاج إنترنت.
- قفل البصمة العتادية للجهاز لمنع سرقة أو نقل النسخة.
- يدعم طباعة الفواتير الحرارية مباشرة على الطابعات.
