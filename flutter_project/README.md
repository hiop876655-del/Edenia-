# إيدينيا - حِسبة | Idenia Hisba (Native Flutter Desktop & Android)

نظام محاسبة ونقاط بيع سريع (POS) مصمم للعمل محلياً 100% بدون إنترنت للتجار والمحلات التجارية على نظامي **الويندوز (Windows Desktop)** و **الأندرويد (Android)**.

---

## طريقة استخراج ملفات التثبيت الجاهزة فوراً عبر GitHub (بدون أي برامج على جهازك):

1. **قم بإنشاء مستودع جديد على حسابك في GitHub (New Repository)**:
   - اجعله **Private** (خاص) لحماية كودك وملفاتك.
2. **ارفع محتويات هذا المجلد بالكامل إلى المستودع**:
   - يمكنك سحب وإفلات الملفات مباشرة على موقع GitHub أو باستخدام Git.
3. **التشغيل الآلي (GitHub Actions)**:
   - ستلاحظ فوراً أن تبويب **Actions** بدأ بالعمل تلقائياً لوجود ملف العمل `.github/workflows/build_apps.yml`.
   - يقوم سيرفر مخصص بتثبيت بيئة Flutter و Android SDK و Visual Studio C++ في السحاب.
4. **تنزيل ملفات التثبيت النهائية**:
   - بعد انتهاء البناء (خلال 3 إلى 5 دقائق)، ادخل إلى قائمة الـ Run الأخيرة، وستجد تحت خانة **Artifacts**:
     - `Idenia-Hisba-Android-APK`: ملف تثبيت أندرويد حقيقي أصلي جاهز للعمل على الهواتف وماكينات نقاط البيع (POS).
     - `Idenia-Hisba-Windows-ZIP`: حزمة الويندوز الكاملة تحتوي على `idenia_hisba.exe` ومحرك التشغيل وقاعدة بيانات SQLite للعمل بدون إنترنت.

---

## طريقة البناء المحلي (إن كان لديك Flutter على جهاز الكمبيوتر):

```bash
# تثبيت الحزم
flutter pub get

# بناء تطبيق الأندرويد APK
flutter build apk --release

# بناء تطبيق الويندوز EXE
flutter config --enable-windows-desktop
flutter build windows --release
```

## مواصفات النظام:
- قاعدة بيانات: SQLite محلية 100% مع تشفير كامل.
- طباعة الفواتير: دعم مباشر للطابعات الحرارية وإصدار PDF.
- الباركود: متوافق مع كافة قارئات الباركود اللاسلكية والسلكية عبر منفذ USB.
