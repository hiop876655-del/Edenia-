# إيدينيا - حِسبة | Idenia Hisba (Unified Desktop & Mobile App)

نظام إدارة المبيعات ونقاط البيع السريعة (POS) والمخازن والحسابات.
نفس واجهة وتصميم وتخطيط المعاينة بنسبة 100%.

## الميزات:
- أوفلاين 100% بدون إنترنت.
- نسخة الويندوز الرسمية (Electron Setup & Portable EXE).
- اختصارات لوحة المفاتيح الفورية (F1, F2, F9, Space, Esc).
- نظام تشفير البيانات وحمايتها محلياً.

## كيفية البناء الآلي واستخراج ملفات التثبيت:
بمجرد رفع هذا المستودع إلى GitHub:
1. اذهب لتبويب **Actions**.
2. ستجد عملية البناء `Build and Release Idenia Hisba` تعمل تلقائياً.
3. خلال دقائق ستجد ملفات التثبيت جاهزة للتحميل في قسم **Artifacts**:
   - `Idenia-Hisba-Windows-Release` (ملف التثبيت التلقائي `Setup.exe` وملف المحمول `Portable.exe`).
